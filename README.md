# Git Demo Repository

## Overview
This repository demonstrates basic Git operations, including creating a repository, branching, making changes, and committing updates.

## Changes Made
### 1. Created a New Repository
- Initialized a new repository on GitHub named `git-demo`.
- Cloned the repository to the local machine.

### 2. Created a New Branch
- Created a branch named `feature-update` using:
  ```bash
  git checkout -b feature-update
  ```

### 3. Updated README.md File
- Added a new section describing the repository.
- Included a list of all changes made in this branch.

### 4. Committed and Pushed Changes
- Staged the modified `README.md` file:
  ```bash
  git add README.md
  ```
- Committed the changes with a message:
  ```bash
  git commit -m "Updated README with feature update"
  ```
- Pushed the branch to GitHub:
  ```bash
  git push origin feature-update
  ```

### 5. Created a Pull Request
- Opened a pull request on GitHub to merge `feature-update` into `main`.
- Reviewed and submitted the request for approval.

## Next Steps
- Merge the pull request once reviewed.
- Continue making improvements as needed.
